# Avoid Figures!!

## What is this?

A small arcade-style action game. Avoid dangerous circles and rectangles to survive as long as you can!
You can also aim for getting as many points as possible.

Also, this is my first game. Since it was abandoned for 3+ years, unexpected bugs may be found. <br>
(The graphic is also very sloppy...🙁)
